# Event-driven-stock-trading

台股**事件驅動監控 agent**：自動抓取未來除權息、面額變更（股票分割）等公司行動，依規則評分，產出可提前布局的關注清單。

> 這是研究／提醒工具，**不是自動下單系統，也不是投資建議**。

## 策略評估（先看這段）

你提到的 `5314 世紀` 案例，本質上通常疊了兩層：

1. **公司行動催化**：面額變更（1 拆 20）或高額股票股利，讓股價「看起來變便宜」、流通張數變多。
2. **題材／動能**：無人機、政策、市場情緒等。分割本身不創造價值，但會改變交易心理與籌碼結構。

### 哪些事件比較值得監控？

| 事件類型 | 關注價值 | 說明 |
| --- | --- | --- |
| 面額變更／股票分割 | 高 | 恢復買賣日容易有投機熱度；適合做「行事曆提醒」 |
| 強制融券回補／停券 | 中高 | 空方須在期限前還券，**但要搭配融券餘額／使用率**；餘額很低時軋空意義有限 |
| 可轉債董事會／掛牌 | 中高 | 決議、收足債款、掛牌常有題材；同時留意可轉債偏稀釋 |
| 高額股票股利（除權） | 中高 | 類似實質分割，歷史上較常出現回補／炒作敘事 |
| 純現金除息 | 中低 | 「除息後會回補」並非穩定 edge，要看殖利率、除息前是否已漲多、大盤環境 |
| 現金增資／認購 | 低（另類） | 偏稀釋，策略邏輯不同 |

### 歷史面額變更的粗略證據

本專案可用 `python -m event_agent backtest-par-value` 重跑。以 FinMind `TaiwanStockParValueChange` + 真實日 K（約 2019 後樣本）觀察：

- 恢復買賣日收盤 **高於參考價** 的比例約 **八成**
- 收盤接近漲停（≥9%）約 **三成**
- 平均恢復日報酬約 **+3% 量級**

但務必注意：

- 樣本很少，統計不穩
- 會分割的股票常已是熱門股（選擇偏誤）
- 回測假設靠近參考價；若你在**停止買賣前**布局，成本、波動、停牌期間機會成本都不同
- `5314` 後來的連續漲停，除權只是催化，不能外推成「凡除權必連板」

**結論**：做一個「未來事件提醒 + 優先序評分」的 agent **值得做**；若要把「高上漲機率」當成可規模化交易系統，還需要更完整的回測（含停止買賣前進場、滑價、停損、題材過濾）。本 repo 先把監控與研究底座落地。

## 功能

- 抓取 **上市** 除權除息預告（TWSE OpenAPI `TWT48U_ALL`）
- 抓取 **上櫃** 除權除息預告（TPEx `tpex_exright_prepost`）
- 抓取 **上櫃面額變更預告**（TPEx `pvChgAnn`）
- 抓取 **上市／上櫃停券（強制融券回補）預告**，並串接融券餘額／使用率
- 抓取 **可轉債** 即將掛牌資料，以及重大訊息中的董事會／發行進度
- 合併最新收盤價，估算現金殖利率
- 規則評分（A/B/C/D）並輸出 Markdown + JSON 日報（含軋空／可轉債專區）
- 面額變更恢復日簡易回測
- **今年（YTD）三策略回測**：除權息回補、融券回補代理、可轉債掛牌（含面額變更），並挑高勝率標的

## 快速開始

```bash
python -m pip install -r requirements.txt

# 產生今日關注清單
python -m event_agent monitor

# 不抓價格（較快）
python -m event_agent monitor --no-prices

# 面額變更歷史回測
python -m event_agent backtest-par-value

# 今年事件策略回測 + 高勝率選股
python -m event_agent backtest-2026
```

輸出預設在 `output/`：

- `watchlist_latest.md` / `watchlist_latest.json`
- `backtest_par_value.md` / `backtest_par_value.json`
- `backtest_2026_latest.md` / `backtest_2026_latest.json`

## 評分邏輯（透明規則）

分數代表「提前關注優先序」，不是上漲機率：

- **面額變更**：基礎高分；換股率越高越加分；若還能在停止買賣前布局再加分
- **強制融券回補**：基礎分 + 停券原因；融券餘額／使用率越高越加分。餘額與使用率都太低時，**不算高關注**
- **可轉債**：董事會決議／收足債款為早期訊號；掛牌日再提高關注；發行規模與轉換價溢價會加減分
- **含股票股利**：依配股率加分；超高配股（例如 >50%）接近「實質分割」
- **純除息**：分數較保守；殖利率高才加分
- **ETF／債券／特別股**：降權，避免噪音

等級：`A ≥ 65`、`B ≥ 40`、`C ≥ 25`；A/B 會進入高關注清單。

## 建議工作流

1. 每日開盤前跑 `monitor`
2. 先看日報裡的「強制融券回補／軋空觀察」與「可轉債觀察」專區
3. 只把 A/B，且融券餘額／可轉債進度站得住腳的標的，放進人工複查清單
4. 對面額變更／高配股／可轉債標的，再確認題材、籌碼、流動性與風險
5. 有餘力可再接：融券變化率、CB 溢價追蹤、Line／Email 推播
